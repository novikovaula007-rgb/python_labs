# лабораторные работы python по предмету "программирование и алгоритмизация"

репозиторий содержит решения лабораторных работ по программированию на python.

## 🚀 запуск скриптов

запуск любых заданий выполняется из корневой директории через модуль python:

```bash
# общая схема:
python -m src.lab{номер_лабы}.{имя_файла}

# примеры:
python -m src.lab02.01_arrays
python -m src.lab02.02_matrix
```
